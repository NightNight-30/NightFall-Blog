本页说明 NightFall Blog（以下简称「本站」，域名 `nightfall7.top`）在用户访问过程中收集、使用与共享信息的情况。使用本站即表示接受本说明。

## 一、本站收集的信息

本站为静态博客，由 GitHub Pages 托管，**不在服务端存储用户的个人身份信息**。仅以下信息会通过浏览器与本站后端交互：

| 信息类型 | 收集途径 | 用途 | 存储位置 |
|---|---|---|---|
| 评论昵称、邮箱、网址 | 评论框提交 | 显示评论作者身份、回复通知 | Artalk 后端（`api.nightfall7.top`） |
| 主题偏好（白天/夜间） | 浏览器 localStorage `Stellar.theme` | 记住用户下次访问时的主题 | 用户本地浏览器 |
| 访问量统计 | busuanzi 脚本 | 页脚显示本站总访问量 | busuanzi 服务端（第三方） |

## 二、第三方服务

本站引用了以下第三方服务，其数据处理受各自隐私政策约束：

- **Artalk**（自托管于 `api.nightfall7.top`）：评论系统。邮箱仅用于回复通知与 Gravatar 头像，不会公开展示完整邮箱。
- **busuanzi**（`busuanzi.ibruce.info`）：访问量统计，仅记录 PV/UV 计数，不收集个人身份信息。
- **GitHub OAuth**（如启用）：用于评论登录。仅获取 GitHub 昵称、头像、邮箱，不申请其他权限。
- **jsDelivr / GitHub CDN**：静态资源（CSS、JS、字体）分发。
- **Iconify API**：侧栏、页脚小图标按需加载。

## 三、Cookie 与本地存储

本站不主动设置跟踪 Cookie。仅在浏览器本地存储以下内容：

- `Stellar.theme`：用户选择的主题模式（light/dark/auto）
- `Stellar.search`：本地搜索历史（如使用站内搜索）
- `likedEchoIds`：用户在说说页点过赞的说说 ID（防重复点赞）

这些数据**仅存在用户本地浏览器**，不会上传到任何服务器。清除浏览器数据即可删除。

## 四、用户权利

- **删除评论**：可在评论管理页或联系博主删除自己发布的评论
- **撤回授权**：在 GitHub Settings → Applications 撤销对本站的 OAuth 授权
- **清除本地数据**：浏览器设置中清除站点数据即可
- **请求信息**：如需查询你被存储的评论数据，可通过页脚联系方式申请

## 五、安全措施

- 全站强制 HTTPS（TLS 1.2+）
- Artalk 后端仅在内网监听，通过 Nginx 反代对外
- 评论邮箱在数据库中存储，不会公开展示
- 不主动向第三方出售或共享用户数据

## 六、未成年人

本站内容主要面向技术开发者，不针对 13 岁以下未成年人。如发现未成年人提交了个人信息，可联系博主删除。

## 七、变更

本说明可能随站点功能演进而更新。重大变更会在页脚或公告区提示。最近更新日期见页面顶部。

## 八、联系

如对隐私有任何疑问或请求，可通过页脚的 GitHub / Gitee 联系博主。
